“clinical-storyboard” Kit: Deliverable Architecture

Select how the Open Design template structures and packages the clinical deliverables (stories, visual cards, guides) for therapists and parents.

A

Static Single-File Bundle (Ultra-Portable)

Compiles all 6 storyboards, printable visual cards, and the parent generalization guide into a single self-contained index.html. Zero external assets, completely portable, and works instantly offline or on a tablet device.

B

Multi-Spread Folder Hierarchy (Modular & Editable)

Structures a modular, clean folder tree: /decks/01-stay-close/, /decks/02-water-safety/, /guides/parent-workbook/. Each lesson is separate, allowing teachers and parents to edit, compile, and validate cards as focused sub-systems.

C

Dynamic SPA Navigation (Web-App Prototype)

Builds a single-page web app with left-rail navigation tabs, persistent local storage, and dynamic sliding panel indicators. Let's therapists toggle between stories, track progress, and customize child profiles in real-time.
